Function Definitions ▼
Python 
def create_event(event: EventCreate) -> EventResponse:
    # body
    return EventResponse(...)
TypeScript 
function createEvent(event: EventCreate): EventResponse {
    // body
    return new EventResponse(...);
}
Key difference: Language A uses function and curly braces. Language B uses def and indentation.
Async / Await ▼
Python 
async def fetch_data() -> dict:
    return {"status": "ok"}
TypeScript 
async function fetchData(): Promise<Record<string, string>> {
    return { status: "ok" };
}
Note: Language A returns a Promise type explicitly. Language B's async machinery wraps it automatically.
Error Handling ▼
Python 
try:
    result = risky_operation()
except ValueError as e:
    log(f"Got error: {e}")
    raise
finally:
    cleanup()
TypeScript 
try {
    const result = riskyOperation();
} catch (e) {
    console.log(`Got error: ${e}`);
    throw;
} finally {
    cleanup();
}
Mapping: try/except → try/catch. raise → throw. as e binds the exception like catch (e).
